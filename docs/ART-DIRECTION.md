# Celestial Egg Rush art direction

## Intent

The game uses an original anime-inspired, cel-shaded visual language: a
twilight academy arena where glowing eggs are contested between player bases.
It is not based on any existing anime, character, setting, logo, map, or
third-party asset.

## Palette and gameplay language

| Element | Color direction | Meaning |
| --- | --- | --- |
| Ground and boundary | midnight navy and violet | safe readable silhouette |
| Central arena | saturated violet | contested focal point |
| Cover | magenta | route break and steal opportunity |
| Egg spawn | pink neon | collectible target |
| Deposit zone | cyan neon | safe return destination |
| Treadmill | gold neon | training and progression |
| Hatch zone / rare reward | purple and gold | creature progression |

The HUD uses the same navy, cyan, pink, and gold palette. Persistent UI stays
at the edges so the third-person playfield remains readable; feedback is
temporary and centered above the lower playfield.

## Asset policy

Use Parts, original mesh work, and original UI art by default. Before any
external asset is admitted, record its license and inspect it for embedded
scripts. Do not import free models with unknown scripts and do not recreate
recognizable characters, environments, names, or symbols from an existing
anime or Roblox experience.

## Next art milestones

1. Add original base signs, egg pedestals, and low-poly foliage after base
   ownership is implemented.
2. Replace graybox cover with original modular architecture.
3. Add original creature models and animations only after persistence and
   inventory limits are production-ready.
4. Test the palette in mobile graphics quality before adding particles or
   extra lights.
